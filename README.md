# 💼 Job Application Form

A responsive and interactive **Job Application Form** built using HTML, CSS, and JavaScript. This project demonstrates form validation, file uploads, user input handling, and dynamic application display.

## 📌 About the Project

The Job Application Form is a frontend web development project designed to collect job applicant information through a structured form. JavaScript is used to validate user inputs, handle file selections, and display submitted application details dynamically on the webpage.

## ✨ Features

- 👤 Applicant name and email input
- 🔐 Password validation
- 🎂 Date of birth validation
- 👥 Gender selection
- 💼 Job role selection
- 💻 Skills selection using checkboxes
- 📷 Profile photo upload with preview
- 📄 Resume upload and file selection
- 📝 Cover letter input
- ✅ Form validation with error messages
- 📋 Dynamic display of submitted applications
- 🗑️ Delete application functionality
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** – Form structure and input elements
- **CSS3** – Styling, layout, and responsive design
- **JavaScript** – Form validation, DOM manipulation, file handling, and event management

## ✅ Form Validation

The form can validate important applicant information, including:

- Full name and email address
- Password strength
- Date of birth
- Gender and job role selection
- Skills selection
- Profile photo file type and size
- Resume file format and size
- Cover letter and required fields
- Terms and conditions acceptance

Validation messages help applicants identify and correct invalid or missing information before submission.
